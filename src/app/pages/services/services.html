GitHub Pages Hosting Architecture & Backend Boundary Notice

GitHub Pages is a static file web hosting service that serves client-side HTML, CSS, JavaScript, and compiled single-page assets. It does not provide server-side execution runtime (such as Python, Node.js Express, or PostgreSQL databases). To preserve 100% frontend usability without failing network requests or CORS errors, this Angular frontend uses a Clearly Identified Demo Mode Service Gateway for client-side state, simulated latency, and reactive data streams.
