CI Validation

Continuous Integration (CI)

Automates code integration from multiple contributors. Every push and pull request executes dependency resolution (npm ci), automated unit tests (npm test), and Angular production compilation (ng build). CI guarantees that broken code or syntax errors never reach the production branch.

CD Deployment

Continuous Deployment (CD)

Automates releasing verified software to end-users. After CI validation passes on the main branch, CD bundles the compiled browser artifact (dist/lab03/browser) and deploys it to the GitHub Pages global edge network via official deploy-pages@v4 actions.
