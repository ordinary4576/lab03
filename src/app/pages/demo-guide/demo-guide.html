Live Lab Demonstration Checklist & Instructions

Exact step-by-step instructions for demonstrating automatic CI/CD deployment to your instructor.

Branch: main Base: /lab03/
1. Code Edit (VS Code) → 2. Git Commit & Push → 3. CI Validation → 4. Production Build → 5. CD Pages Deploy → 6. Live Site Updated
Step 1

Open the Target File in VS Code

In your VS Code editor, open the primary dashboard template:

src/app/pages/dashboard/dashboard.html

Look for line 16 with the comment <!-- 🎯 PRIMARY DEMO TARGET TO EDIT -->

Step 2

Make a Visible Before-and-After Modification

Locate the release badge element:

Before:
<span id="lab-demonstration-badge" class="demo-pill-highlight">
  🚀 Lab Demo Target: Release v1.0.0 — Production Ready
</span>
After (Example):
<span id="lab-demonstration-badge" class="demo-pill-highlight">
  🚀 Lab Demo Target: Release v1.1.0 — Live CI/CD Verified by Areej!
</span>

Save the file in VS Code (Ctrl + S).

Step 3

Stage, Commit, and Push via Git Bash or PowerShell

Execute these exact commands in your project root terminal (C:\Users\hp\lab03): 

git status
git add src/app/pages/dashboard/dashboard.html
git commit -m "demo: update live demonstration banner to v1.1.0"
git push origin main
Step 4

Observe GitHub Actions CI/CD Execution

Open the repository GitHub Actions page:

{{ actionsUrl }} ↗

  • CI Job: Watch Build & Validate (CI) start automatically. It checks out code, sets up Node.js v24, runs npm ci, runs automated tests (vitest), and executes ng build --base-href /lab03/.
  • CD Job: Once CI succeeds, the Deploy to GitHub Pages (CD) job initiates, uploading the artifact and publishing to GitHub Pages.
  • Duration: The entire automated pipeline typically finishes in 40–60 seconds with green checkmarks.
Step 5

Verify the Updated Live Website

Navigate to your published GitHub Pages URL:

{{ pagesUrl }} ↗

Confirm that your new text (Release v1.1.0 — Live CI/CD Verified) is now immediately visible in the banner!

Troubleshooting Note: If your browser cached the previous page, do a hard refresh with Ctrl + Shift + R (Windows) to instantly fetch the newly deployed bundle.
